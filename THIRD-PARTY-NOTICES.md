# Componentes de terceiros

A licença MIT do GDesktop aplica-se ao código original do projeto. Dependências, ferramentas e o runtime mantêm seus próprios avisos e licenças.

| Componente | Licença / referência |
|---|---|
| .NET / ASP.NET Core / Windows Forms e Microsoft.Data.Sqlite | MIT e avisos de terceiros dos projetos .NET: https://github.com/dotnet/runtime |
| Open XML SDK | MIT: https://github.com/dotnet/Open-XML-SDK |
| PdfPig | Apache-2.0: https://github.com/UglyToad/PdfPig |
| SQLitePCLRaw | Apache-2.0: https://github.com/ericsink/SQLitePCL.raw |
| SQLite | Domínio público: https://www.sqlite.org/copyright.html |
| Script tools/dotnet-install.ps1 | MIT, copyright .NET Foundation e colaboradores, preservado no cabeçalho |
| TesseractOCR / Tesseract (somente experimento opcional) | Apache-2.0: https://github.com/Sicos1977/TesseractOCR e https://github.com/tesseract-ocr/tesseract |
| Inno Setup (ferramenta de empacotamento, não incluída no Git) | Termos próprios: https://jrsoftware.org/isinfo.php |

O runtime autocontido contém outros componentes de terceiros. As cópias dos avisos de licença disponíveis nos pacotes usados na publicação ficam em `licenses` na distribuição. O Windows OCR é um recurso do Windows, sujeito aos termos da Microsoft, e não é redistribuído pelo projeto.
